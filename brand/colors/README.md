# Paleta do Pagespeedfy

| Família | Base | Papel |
| --- | --- | --- |
| Petróleo | `#00161E` | estrutura, texto e superfícies escuras |
| Turquesa | `#2AD5BE` | página do site e vínculo com a Promovaweb |
| Verde | `#22C55E` | velocidade, nota boa e página corrigida |

O verde segue a escala `green` do Tailwind CSS, com `600` fixado em
`#15803D`, o tom do raio nas variantes para fundo claro. No light mode, use
acento textual `#15803D`. No dark mode, use `#86EFAC`. A escala completa e os
estados ficam em `palette.json`; os pares aprovados ficam em
`../accessibility.md`.
